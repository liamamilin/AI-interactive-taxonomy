2 分钟悟懂 AI Agent：交互玩具箱

Agent（智能体）和普通聊天机器人到底差在哪？玩完这 3 个 2 分钟小游戏，亲手体验它如何“装上手脚干活”、如何“撞墙后自己循环纠错”、以及为什么必须给它装上“人工审批闸门”。

① 装上手脚（Tool Calling） → ② 自主循环（ReAct Loop） → ③ 权限闸门（Human-in-the-Loop）
🦾
玩具 01 · 约 2 分钟

手脚装配台

原理：Tool Calling（工具调用）

先看“纯大脑”面对查天气、算账、发邮件时如何一本正经地瞎猜，再亲手给它插上不同工具卡，观察它如何自动调度外援完成任务。

顿悟点：Agent = 大脑（LLM）+ 手脚（工具），从“只会动嘴”进化到“真的动手”。

玩具 02 · 约 2 分钟

ReAct 迷宫特工

原理：ReAct 循环（思考 → 行动 → 观察 → 纠错）

派特工去迷宫拿宝箱，你还可以随时放路障捣乱！对比普通问答“撞墙就摆烂”与 Agent 循环试错、找钥匙、绕路破局的全过程。

顿悟点：普通 AI 是一问一答，Agent 是给一个目标，自己观察报错并循环重试直到搞定。

玩具 03 · 约 2 分钟

失控的实习生：权限闸门

原理：任务拆解 & Human-in-the-Loop（人类审批）

把邮箱清理和发合同交给实习生 Agent，调节“自主权滑块”：体验手把手模式有多累、全自动放飞如何 3 秒社死，以及高危刹车如何救场。

顿悟点：好 Agent 不是放任不管，而是常规操作全自动、高危动作前自动刹车等你点头。
